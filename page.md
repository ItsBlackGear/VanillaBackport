<!-- What is VanillaBackport? -->
<h2 style="margin: 12px 0 4px;">
  <strong>What is VanillaBackport?</strong>
</h2>

<p style="text-align:justify; margin: 4px 0;">
  Formerly known as Extended Nether Backport, Caves &amp; Cliffs Backport and The Wild Backport respectively.
</p>

<p style="text-align:justify; margin: 4px 0 10px;">
  The mod became a mashup of backports in order to support more versions and better compatibility between our backports.
</p>

<!-- What updates are ported -->
<h2 style="margin: 12px 0 4px;">
  <strong>What updates / drops are currently ported?</strong>
</h2>

<p style="text-align:justify; margin: 4px 0 10px;">
  The development of my backport mods have been in hiatus for a while, but I've decided to reignite the project and there's so much content to work with, there's a detailed roadmap provided in the
  <a href="https://github.com/ItsBlackGear/VanillaBackport/wiki">Github Wiki</a>
  showing what updates have been ported and their target versions!
</p>

<!-- Will X update be ported -->
<h2 style="margin: 12px 0 4px;">
  <strong>Will X update be backported?</strong>
</h2>

<p style="text-align:justify; margin: 4px 0 10px;">
  Most likely! there's plans for most versions to be supported, however the scope of this mod is adding <strong>main features only</strong> meaning that most bug fixes, technical or graphical changes will not be included in the mod.
</p>

<!-- 1.12.2 -->
<h2 style="margin: 12px 0 4px;">
  <strong>Will there be 1.12.2?</strong>
</h2>

<p style="text-align:justify; margin: 4px 0 10px;">
  Sadly my answer to this is no, there is already a wide range of versions to work on since VanillaBackport is planned to support from 1.16.5 to the current versions. In addition to that, 1.12.2 has already a very obsolete database which I don't have any intentions to dive into.
</p>
